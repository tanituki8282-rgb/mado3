# 窓3 — 核（正本抜粋）

作業名: **窓3**  
出典: `正本_窓3.md` / `素子_採否と核の提案.md`（2026-10-26）

## 核（一文）

**「見える窓は手札3＋次1だけ。その狭い先読みで、AP（今の手数）とMP（貯めた手数）をどちらに割くか。」**

## ユーザー固定（触らない）

- 手札上限 **3**。使用したら補充し、常に3枚。
- **次ドロー1枚**が見えている。
- **捨て札なし**。使用カードはデッキへ戻る（ドローはランダム）。
- リソースは二系統:
  - **AP**: マナ相当。毎プレイヤーターン開始時に固定値へリセット（仮: 3）。
  - **MP**: ターン経過では回復しない。カード・イベント効果でのみ増減。
- カードは **イラストなし・文字のみ**。
- **お金・買い物**あり（購入・山から削除）。

## ターン構造（第一版）

敵意図確定 → プレイヤーが手札から好きなだけ使用（AP/MPが足りる限り）→ 手札は常に3に戻る → 終了宣言 → 敵実行 → **プレイヤーブロック清算**。

### ブロック（明確化・R1）

- **プレイヤーブロック**: 敵行動のあと清算（そのターンの攻撃を防ぐ）。
- **敵ブロック**: 敵が得たブロックは **次のプレイヤーターン中有効**。敵の次アクション開始時にクリア。意図の「防御」は読む価値がある。

## 「次」の扱い

カードを1枚使うたびに、見えていた次が手札に入り、新しい次が山から見える。  
窓操作（先読み・入替・集中）は **窓の中だけ** をいじる。意図と次が合うと「読めた」報酬（ブロック/+攻撃、戦闘初回はMP+1）。合う条件は常時表示（攻撃意図→防御札／殻・強化→攻撃札）。  
読めたは窓バフ＋トースト。ラン初回は教示で1回保証。不一致時は探りブロック+1。

## 反肥大（Review3 / R28）

山が厚いと次1の情報価値が死ぬ。報酬は肥大時2択、**16枚超は1択**＋スキップ推奨。店の削除は厚いほど安い。スターターは薄め（~11）。

## MP の役割（明確化）

- (a) 決め手コスト（決壊 AP1/MP2・気爆・貫通・弱体）— **MPが主動詞**
- (b) 未来操作（先読み・深読み・窓入替・窓選替・次を埋める）
- 報酬はデッキにMP消費札が無い間、店なしでspend候補を保証。休憩の気の欠片も保険。
- 戦闘開始時 MP は 0。蓄気・気吸い・導気・イベントで貯める。
- 初戦のみ戦闘限定『膜裂き』が**手札／次に出る**（任意・山漁りなし）。恒常山札には残らない。
- 戦闘ごとに1回「気の往復」で AP↔MP を1点移せる。
- 殻／精鋭／ボスでMP未消費のままターンを重ねると**気滞**（敵ブロック+4）。初回MP消費でブロック+2。
- 手札が全部灰色なら「詰み脱出」で次を無料入替（戦闘1回）。
- 殻持ち敵は AP 削りだけでは長い → MP 投資が効く。
- 窓瞑想は HP-10。精鋭戦では瞑想余波で敵が硬化しうる。

## 精鋭ペース（R36）

精鋭は短く尖らせる（HP~54・4ビート）。グラインドで核の味を殺さない。

## 第一版の勝敗

- 勝利: 1アクトのボス撃破
- 敗北: HP0
