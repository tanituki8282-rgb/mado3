## 核（一文）

**「見える窓は手札3＋次1だけ。その狭い先読みで、AP（今の手数）とMP（貯めた手数）をどちらに割くか。」**

## ユーザー固定（触らない）

- 手札上限 **3**。使用したら補充し、常に3枚。
- **次ドロー1枚**が見えている。
- **捨て札なし**。使用カードはデッキへ戻る（ドローはランダム）。
- リソースは二系統:
  - **AP**: マナ相当。毎プレイヤーターン開始時に固定値へリセット（仮: 3）。
  - **MP**: ターン経過では回復しない。カード・イベント効果でのみ増減。
- カードは **イラストなし・文字のみ**。
- **お金・買い物**あり（購入・山から削除）。

## ターン構造（第一版）

敵意図確定 → プレイヤーが手札から好きなだけ使用（AP/MPが足りる限り）→ 手札は常に3に戻る → 終了宣言 → 敵実行 → ブロック清算。

## 「次」の扱い

カードを1枚使うたびに、見えていた次が手札に入り、新しい次が山から見える。

## 第一版の勝敗

- 勝利: 1アクトのボス撃破
- 敗北: HP0

## スコープ外

イラスト、遺物動物園、Exhaust/捨て札山、ポーション、複数アクト、Godot本体。
